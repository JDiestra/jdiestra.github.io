Apuntes

Una biblioteca, varias formas de trabajar

La aplicación combina tarjetas, lista, tabla, agenda y kanban con búsqueda, etiquetas, historial y recuperación.

React · Node.js · SQL Server

El problema

Las notas y tareas necesitan conservar su contexto al pasar de una biblioteca a una agenda o un tablero.

Decisiones de implementación

  • Conservar la misma biblioteca al cambiar de vista.
  • Recuperar versiones como borrador antes de guardar cambios.
  • Confirmar la escritura local y sincronizar después, según la configuración documentada.

Alcance y límites

Se describe la implementación local y sus flujos. El acceso y la sincronización dependen del entorno; no se presenta como servicio público.

Descripción basada en documentación y código local. La contribución individual, las fechas y los resultados medidos están pendientes de confirmar.
