Asignación operativa

Motor de asignación y supervisión

El proyecto reúne una torre de control, un evaluador determinista compartido con un simulador y un flujo de asignación con revisión humana.

React · TypeScript · NestJS · PostgreSQL

El problema

Coordinar solicitudes, disponibilidad y cobertura requiere criterios consistentes y una revisión clara de las excepciones.

Decisiones de implementación

  • Separar la evaluación de candidatos de las operaciones de entrada y salida.
  • Compartir las reglas entre API y simulador para comparar escenarios.
  • Mantener trazabilidad de decisiones y derivar excepciones a revisión.

Alcance y límites

La documentación y el código incluyen simulación offline y un modo piloto supervisado. No se afirma un despliegue productivo ni una mejora cuantificada.

Descripción basada en documentación y código local. La contribución individual, las fechas y los resultados medidos están pendientes de confirmar.
