Sistema de diseño React

Componentes con un lenguaje común

Una biblioteca React organiza tokens, estilos compartidos, componentes y ejemplos en Storybook.

React · TypeScript · Storybook

El problema

Varias interfaces necesitan controles coherentes y una forma clara de consultar sus variantes.

Decisiones de implementación

  • Separar tokens visuales y estilos de componentes.
  • Exponer una API pública para el consumo desde aplicaciones.
  • Documentar estados y variantes junto a cada componente.

Alcance y límites

El repositorio contiene exports y documentación de consumo. La existencia de componentes no implica una certificación de accesibilidad; cada integración necesita validación.

Descripción basada en documentación y código local. La contribución individual, las fechas y los resultados medidos están pendientes de confirmar.
